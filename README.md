#College Database System

A university project aimed at managing student and teacher data and facilitating registration and linking between them.

## 💡 Overview
This system was developed as part of a university project to learn to connect Java applications to SQL Server databases. The project focuses on managing relationships between different entities within the academic environment.

## 🛠 Tasks and responsibilities
This project is the result of cooperation between a team of three developers:
- I was responsible for: designing the database, preparing tables, and implementing the communication process between the application and the database (Connection & Backend Logic).


## 🚀 Techniques used
- **Language**: Java
- **Database**: SQL Server
- **IDE**: NetBeans IDE

## 📝 Note about the project
The project is an educational demo version that covers the basic interfaces for students and teachers, and focuses mainly on the efficiency of connecting to the database and dealing with queries (SQL Queries).
